# Sage & Bloom — Chennai Residential Builder

Static multi-page website structured for a three-member development team.

## Structure
- `components/` — reusable source snippets for shared header, footer, CTA and project cards.
- `css/` — global styles plus page-specific styles and a real responsive layer.
- `js/` — navigation, reveal effects, project filtering, contact form and auth demo behaviour.
- `pages/` — primary content pages.
- `projects/` — individual project detail pages with previous/next navigation.
- `images/` — local SVG image assets; no remote image URLs are required.

## Content note
The builder name, contact details and project facts are prototype placeholders until the real builder supplies verified information. Chennai SEO copy is intentionally written around residential builder, apartments, 2 BHK, 3 BHK and project-intent searches.
